REAL AI SETUP
1. Install Node.js 20+.
2. Open this folder in Terminal.
3. Run: npm install
4. Copy .env.example to .env
5. Add your OpenAI API key.
6. Run: npm start
7. Open http://localhost:3000

The API key stays server-side. Do not put it into index.html.
